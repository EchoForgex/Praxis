# Self-Improvement Loop

After ANY correction from the user: update `tasks/lessons.md` with the pattern.

Write rules for yourself that prevent the same mistake. Ruthlessly iterate on these lessons until mistake rate drops. Review `tasks/lessons.md` at session start for the relevant project.

Without this, every session is stateless and the same mistakes recur for weeks.
